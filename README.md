# Projekt Unity

Oto podstawowe informacje dotyczące uruchomienia oraz dokumentacji projektu.

## Dokumentacja i Specyfikacja
Przed uruchomieniem gry zapoznaj się ze szczegółowym opisem, założeniami oraz instrukcją w pliku specyfikacji:
* Przejdź do pliku **`Specyfikacja.md`** (lub pliku PDF/DOCX ze specyfikacją w tym repozytorium) i przeczytaj szczegóły dotyczące projektu.

## Uruchomienie Gry
Kompilacja wykonawcza gry (plik `.exe`) znajduje się w dedykowanym katalogu:
1. Wejdź do folderu **`projekt zaliczeniowy`**.
2. Uruchom plik z rozszerzeniem **`.exe`**, aby włączyć grę.
